# Trial Chamber Practice Map (pre-release)

This is a Minecraft practice map for Trial Chambers aimed at Draftout.

## Features

The map allows for semi-custom Trial Chamber generation by allowing the player to select specific rooms such as the Entrance, Intersection, and End Room, as well as the End Chamber, the Intersection Chamber and even the Entrance Tree. The map allows for the player to choose spawner types for the Melee, Small Melee and Ranged category. Since the names for some of the rooms are generic file names, I, GracefulBeauty and Danny15_ have given names for them. We have replaced the name of the "Slanted" chamber to "Maze" since it more accurately describes what the room looks like.

The player is able to choose a spawnpoint or leave it randomized and a fresh Trial Chamber is generated for every run. Similar to Llama's Bastion Practice, the map waits for movement before beginning a timer and switching the player to Survival mode.

The player can turn Mobs in the Trial Chamber ON or OFF, and at the moment can end their runs by either dying with no set spawn within the Trial Chamber, or throwing out their best pickaxe(s). If you only have 1 pickaxe, throwing it out will end the run. If you have 2, throwing the worse one will do nothing. If you have 2 of the same pickaxe, throwing one will do nothing.

The player is able to customize and pick between three different Loadouts while in the lobby, being able to save hotbar, inventory, offhand and armour slots. (The layout for this is inspired again by Llama's Bastion Practice, though none of the code has been taken from that map.) One loadout is saved using some typical items and junk you might have on a real digdown. The second loadout just has stone tools. The third is left empty.

## Planned Features for Full Release

Next planned is a "Digdown" setting will be added, toggling between OFF / Dry / Wet. This will give the "Ends When: Exit" option a function whereby you need to return to your Digdown spot to 

Another User Interface will be added to the lobby to select "Goals" to mimic an actual Draftout game. Toggling certain goals ON or OFF will allow detection of their completion within a run, which will tell you the timestamp and that you completed the goal. There are about 50 canditates for Draftout goals relevant to Trial Chambers, implementation may be slow.

A builder has agreed to improve the Lobby from its current simplistic state, and it will be changed to fit other UI elements such as Text Displays and the Goal Selector.

A randomizer is planned for Goals, so that players can test their ability to adjust to lines that they themselves have not set. It is NOT planned that having a certain goal on will guarantee ability for that goal to be completed. 

I am thinking of ways to mimic the in-game Draftout board in a practice map. My two previous maps (Jungle Temple and Igloo) have used the Sidebar, but this is limited to the number of entries. Something like a way to open a Chest menu with the goals in a bingo-like grid would be similar to how "B" opens the Board in Draftout and would allow hovering over the goals to show info about Goal progress.
