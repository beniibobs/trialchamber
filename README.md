# Trial Chamber Practice Map v1.0

This is a Minecraft practice map for Trial Chambers aimed at Draftout. It is intended for use in Java Edition version **26.3.**

## Installation

Go to the [latest Release]([url](https://github.com/beniibobs/trialchamber/releases)) and download the .zip file for the world. Extract it to your "saves" path in your Drafout instance (in Prism, click "folder" and make sure your Draftout instance is selected). 

## Features

The map allows for semi-custom Trial Chamber generation by allowing the player to select specific rooms such as the Entrance, Intersection, and End Room, as well as the End Chamber, the Intersection Chamber and even the Entrance Tree. The map allows for the player to choose spawner types for the Melee, Small Melee and Ranged category, as well as whether to force chamber Dispensers to generate instead of the vanilla 50% chance. Since the names for some of the rooms are generic file names, GracefulBeauty, Danny15_ and I have given names for them. We have replaced the name of the "Slanted" chamber to "Maze" since it more accurately describes what the room looks like.

The player is able to choose a spawnpoint or leave it randomized and a fresh Trial Chamber is generated for every run. Similar to Llama's Bastion Practice, the map waits for movement before beginning a timer and switching the player to Survival mode.

The player can turn Mobs in the Trial Chamber ON or OFF, and can end their runs by either Exiting (reaching the top of a digdown) or by Completing all the goals on the Board, or they can end any run by dying with no set spawn within the Trial Chamber, or throwing out their best pickaxe(s). If you only have 1 pickaxe, throwing it out will end the run. If you have 2, throwing the worse one will do nothing. If you have 2 of the same pickaxe, throwing one will do nothing.

The player is able to customize and pick between three different Loadouts while in the lobby, being able to save hotbar, inventory, offhand and armour slots. One loadout is saved using some typical items and junk you might have on a real digdown. The second loadout just has stone tools. The third is left empty. An option to select a Random loadout is also available. 

The Digdown setting spawns the player at the bottom of a 1x1 hole as if they dug into the TC (though sometimes it might carve out part of the room due to the generation). If the setting is set to Wet, then flowing water will generate as soon as the player moves. If "Dig In" is on, the player will be 1 block from falling into the room.

## Goals

There are **75** Draftout goals implemented into the map, and these are the goals most often associated with TC lines, or at least doable as part of a TC line. You can randomize the goals on the board, as well as build a semi-custom, semi-random board, or a fully custom board using the goals. You can omit certain goals from the randomizer pool if you do not want them coming up. 

By default a small board is on the Sidebar, with low quality icons. To see the bigger board and to see goal progress, press your Quick Actions hotkey (Settings --> Controls).
